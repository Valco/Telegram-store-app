# Telegram Bot Store: Опис фішок та План реалізації

## 1. Функціонал (Фішки) проекту

### 🌐 Загальне & Архітектура
- Модульне файлове сховище (можливість перемикання між локальним сервером та Amazon S3 безпосередньо з Адмін-панелі без зміни коду).
- Інтеграція Google Analytics та Meta Pixel.
- Поля для введення ID пікселів/аналітики та налаштування S3 в налаштуваннях сайту (з адмінки).
- Мультиканальність: одна спільна база даних для ТГ Міні-апп та Веб-сайту.
- **🛡 Безпека платежів:** Інтеграція Webhooks із обов’язковою математичною (криптографічною) верифікацією підписів від Monobank, що унеможливлює фейкові оплати. Серверний перерахунок кошика.
- **🧾 Фіскалізація (ПРРО):** Автоматична видача електронних фіскальних чеків після успішної оплати (через інтеграцію, наприклад, Checkbox) з авто-надсиланням чеку в Telegram/Email покупця.
- Захист (Rate Limiting) від масових спам-запитів.

### 📱 Telegram Mini App (TMA)
- **Головна сторінка:**
  - Віджет лояльності (на зразок AliExpress) з актуальною кількістю монет.
  - Нагадування про щоденний візит для отримання бонусних монет.
  - Кнопка-перехід на сторінку "Пропозиції" з акційними товарами.
  - Блок "Рулетки" при першому вході зі знижками 5-75% на 60 хвилин (з живим таймером).
- **Гейміфікація та Лояльність:**
  - Нарахування монет за: щоденні візити (check-in), відгуки, рефералів, підписки/репости.
  - Оплата монетами до X% від вартості замовлення (відсоток налаштовується в адмінці).
- **Навігація & Пошук:** Перегляд каталогу, розбивка за категоріями, пошук товарів.
- **Картка товару:**
  - Фото (1-8 шт) + Відео (опціонально).
  - Опис, розміри, вартість, категорія.
  - Статус: "В наявності" або "Виготовлення на замовлення" (із зазначенням терміну).
- **Оформлення замовлення (Checkout):**
  - Оплата через Monobank (включає Apple Pay / Google Pay / введення картки).
  - Доставка Новою Поштою (інтеграція API для автозаповнення міст/відділень) та Укрпоштою.
  - **Обовʼязкова** галочка "Дані замовлення перевірені".
  - Галочка "Можна не перетелефоновувати".
  - Поле "Коментар до замовлення".
- **Утримання клієнта (Retention):** 
  - Нагадування від бота про "покинутий кошик".

### 💻 Інтернет-магазин (Веб-сайт)
- Адаптивний дизайн (десктоп, планшет, мобайл браузер).
- Повний функціонал, аналогічний TMA (каталог, пошук, картка товару, оформлення).
- Робота пікселів та аналітики для SEO та реклами.

### ⚙️ Адмін Панель
- **Каталог:** Додавання, редагування, видалення товарів/категорій. 
- Категорії можуть бути вкладеними (наприклад: Іграшки -> Italian Brainrot). Налаштування статусу "Виготовлення на замовлення + термін".
- **Користувачі та Ролі (RBAC):** Керування клієнтами та гнучкий розподіл рівнів доступу (Суперадмін, Адмін, Менеджер, Глядач). Система прав доступу застосовується до сторінок адмінки.
- **Налаштування платформи та лояльності:** 
  - Встановлення максимального % оплати замовлення монетами.
  - Налаштування ймовірності випадіння конкретних знижок у "Рулетці".
  - Конфігурація файлового сховища (перемикач: `Тільки локально` / `Amazon S3` + введення AWS ключів).
- **Відкладений постинг:** Можливість призначити дату та час публікації конкретного товару в офіційному ТГ-каналі (з авто-посиланням у Mini App).
- **Замовлення та Логістика:**
  - Керування статусами замовлень.
  - Генерація ТТН (Нової Пошти) прямо з адмінки.
- **Сповіщення:** Миттєві повідомлення про нові замовлення на Email та у закритий ТГ-чат адміністраторів.
- **Експорт:** Генерація XML/YML списків товарів (шаблон як для PROM).

## 2. Поетапний план реалізації

### Етап 1: Проектування Архітектури (System Design & DB)
- Проектування бази даних (PostgreSQL): зв'язки товарів, розмірів, кошиків, історії монет.
- Налаштування локального файлового сховища (з підготовкою інтерфейсу для майбутнього S3).
- Визначення точних відповідей та ендпоінтів API.

### Етап 2: Розробка Бекенду (API) & Інтеграції модулів
- Створення ядра системи на Node.js (напр. NestJS або Express).
- Реалізація авторизації через Telegram.
- Підключення Monobank Acquiring API для платіжного шлюзу.
- Підключення Нової Пошти API.
- Інтеграція Telegram Bot API для розсилки (покинутий кошик, пости в канал, сповіщення адмінам).

### Етап 3: Розробка Адмін Панелі
- Створення графічного інтерфейсу для управління магазином.
- Реалізація CRUD (створення/читання/оновлення/видалення) для товарів, користувачів.
- Реалізація функціоналу генерації ТТН.
- Налаштування блоку інструментів (XML фід, % монет, ймовірність рулетки, ID пікселів).

### Етап 4: Розробка Telegram Mini App (TMA)
- Верстка та логіка інтерфейсу.
- Каталог, швидкий пошук, віджет щоденних бонусів монет, рулетка.
- Налаштування чекауту: обов'язкові галочки перевірки, вибір способу доставки та оплати.

### Етап 5: Розробка Веб-магазину (Десктоп/Мобайл)
- Адаптація та компіляція компонентів для використання не тільки всередині Telegram, а й у звичайному браузері.
- Тестування роботи пікселів аналітики.

### Етап 6: QA Тестування та Розгортання (Deploy)
- Проходження повного циклу: від кліку по рекламі до отримання повідомлення адміном.
- Перевірка безпеки платежів.
- Налаштування сервера і деплой (запуск в production).
